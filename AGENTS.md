## Critical Directives for Agents

1. **Source of Truth**:
   - The production website code is located in `next-app/`.
   - Never directly modify files in `build/` — it is generated by `npm run build`.

2. **People & Leadership Data**:
   - Single source of truth: `next-app/src/data/people.js` (and `src/data/people.js`).
   - Leadership hierarchy order:
     1. Yash Kumar (Founder & Product Lead)
     2. Ved Prakash (Project Head)
     3. Sandeep Kumar (Technical Head)
     4. Rajesh Kumar (AI Integration Engineer)
   - Synchronize AI metadata in `next-app/public/llms.txt`, `llms-full.txt`, and `ai-facts.json`.

3. **Image & CSS Rules**:
   - **Never** use landscape aspect-ratio (like `4/3`) for portrait photos of team members.
   - Always use `aspect-ratio: 4 / 5` (or `3 / 4`) with `object-fit: cover; object-position: center 15%;`.
   - Blog featured images must use `aspect-ratio: 16 / 9; object-fit: cover;`.

4. **SEO, AEO & GEO**:
   - Always ensure Schema.org JSON-LD (`BlogPosting`, `Person`, `Organization`, `FAQPage`) is present.
   - Include direct-answer summary blocks and structured tables for Answer Engine Optimization.

5. **Build & Deploy Process**:
   - Run `npm run build` (Next.js SSG export + sync to `build/`).
   - Push to `main`.
   - Deployment command:
     `cd /home/vayunexs/repositories/vayu-web && git fetch origin main && git reset --hard origin/main && cp -Rf build/. /home/vayunexs/public_html/ && echo "DEPLOYMENT COMPLETE SUCCESS!"`
